## 다운로드
최신 릴리스에서 `myWorkHour-vX.X.X.zip`을 받으세요 →
**[Releases](https://git.mgang.app/mgang4u/myWorkHour-releases/releases)**

## 설치 방법
1. zip 다운로드 후 **압축 해제**
2. 크롬 주소창에 `chrome://extensions` 입력
3. 우측 상단 **개발자 모드** 켜기
4. **압축해제된 확장 프로그램을 로드합니다** 클릭 → 압축 푼 `myWorkHour` 폴더 선택
5. 그룹웨어 근무시간 페이지에서 툴바의 시계 아이콘 클릭

## 주요 기능
- 인정근무를 출퇴근 기준으로 직접 계산 (반차/연차/경조/출장 반영)
- 월간(일 8h) / 주간(주 40h) 기준 선택, 법정휴게·점심 1시간 휴게 옵션
- 다크/라이트/시스템 테마, 대한민국 공휴일 표시
- 페이지 우측 패널 도킹, 월 변경 시 자동 갱신
